# Design pillars

Status: **Accepted**.

The transcript briefly proposed Adventure, Mastery, Creation, and World Memory, then ended with the clearer and later Wonder/Mastery/Consequence triad. The triad is authoritative; adventure, creation, and world memory remain mechanisms that serve it.

## Wonder

> What exists beyond that mountain?

The world communicates possibilities through silhouettes, weather, smoke, roads, sounds, unusual vegetation, moving creatures, and distant structures rather than exhausting the map with activity icons. Rarity must be meaningful, geography must shape routes and history, and discoveries must differ causally as well as cosmetically.

Questions for a feature:

- Does it create a discoverable possibility or reveal a coherent cause?
- Can the player form and test a hypothesis about the world?
- Does it preserve surprise after repeated play?

## Mastery

> I can now do something I could not do before.

Progression combines power with knowledge, movement, crafting, magic, equipment behavior, social influence, navigation, and settlement capabilities. It should open verbs, routes, strategies, and combinations instead of replaying the same activity with larger values.

Questions for a feature:

- Does learning or practice change decisions?
- Does the reward unlock a capability or expressive build choice?
- Does mastery reduce friction without erasing interesting travel or danger?

## Consequence

> What I did actually changed something.

World memory connects action to visible outcomes: repaired or ruined places, changed prices, migration, altered threats, faction control, routes, settlement growth, or new stories. Consequence requires bounded persistence and causal explanation, not the permanent storage of every microscopic event.

Questions for a feature:

- Can the player observe the downstream effect?
- Can developer tools explain why the state changed?
- Is persistence worth its save, simulation, and migration cost?

## Pillar test

A proposed feature should materially strengthen at least one pillar without substantially damaging the others. Failure is a feature-creep signal, not an automatic ban; record the rationale if proceeding.

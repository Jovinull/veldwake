# Gameplay loop

Status: **Proposed**, to validate through vertical slices.

## Core loop

```text
observe a possibility
  -> prepare and choose a route/build
  -> traverse and encounter danger
  -> fight, investigate, harvest, negotiate, or build
  -> gain capability, knowledge, resources, or influence
  -> change local/world state
  -> observe consequences and new possibilities
```

Exploration supplies questions; mastery supplies new answers; consequence makes the answers matter. Construction and world editing are verbs in the RPG, not an obligation to become a pure building sandbox.

## Content quality rules

- World size is not content.
- A location should have visual, mechanical, historical, ecological, or economic reason to exist.
- Rewards should change plans, abilities, routes, builds, relationships, or world state when possible.
- Generated quests must emerge from understandable needs and conflicts, not only templated errands.
- The player should be able to ignore a problem; simulation may produce bounded, observable consequences.
- Rarity and surprise need controlled distributions so the exceptional remains exceptional.

## First proof slice

The first broad vertical slice should eventually contain one polished region, forest, mountain, small ruin, character, weapon, creature, day/night cycle, and simple weather. It proves terrain, procedural visual identity, movement, one satisfying fight, and basic persistence before scaling content or simulation.

This is not the next milestone; rendering and voxel foundations precede it.
